# FinPath Academy

**Learn money. Understand data. Build your future.**

FinPath Academy is an independent, self-paced financial education platform. It combines a structured online-school experience with practical lessons, guided activities, assessments, and projects. The project is original and is not affiliated with Edmentum.

## Learning pathways

### Personal Finance
1. Money Fundamentals
2. Banking & Saving
3. Employment & Taxes
4. Credit & Debt
5. Investing & Retirement

### Adult Life & Household Finance
6. Household & International Finance

### Financial Data Analysis
7. Financial Data Analysis

## Product principles

- Teach concepts with clear explanations and worked examples.
- Give meaningful feedback, not just right/wrong marks.
- Track lesson completion separately from mastery.
- Use fictional examples for practice; label estimates clearly.
- Start without an account. Save progress locally and provide a backup/export option.
- Add accounts and cloud sync only in a later phase.

## Planned stack

- React + TypeScript + Vite
- Responsive, accessible CSS
- Browser-based progress persistence for the first release
- GitHub for source control; Vercel can be used for deployment

## Development stages

1. Specification and curriculum design
2. App shell and responsive dashboard
3. Course catalog and lesson player
4. Quiz engine and feedback
5. Local progress persistence and export
6. Course content and practical projects
7. Progress reports and review recommendations
8. Optional accounts and cloud sync

## Educational note

FinPath Academy provides general education, not personalized financial, tax, legal, or investment advice. Rules and tax treatment vary by location and may change; learners should verify current information with official sources.
